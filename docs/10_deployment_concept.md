# Deployment Concept

The future deployment is a representative livestock-building scenario, not a completed farm installation. A serviceable node would require a reviewed enclosure, power input, cable protection, sensor placement, contamination controls, maintenance access, network plan, and reference-instrument strategy.

```text
representative livestock environment
 -> sensor node
 -> local acquisition and QA/QC
 -> microSD storage
 -> RS-485 reference path
 -> WiFi/MQTT transport
 -> central storage
 -> dashboard and validation
```

The design-stage concept does not claim ATEX, EMC, environmental qualification, field robustness, or farm performance. Those require engineering review and physical testing.
