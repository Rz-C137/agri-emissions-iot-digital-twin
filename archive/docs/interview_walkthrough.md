# Eight-minute interview walkthrough

I built an independent virtual commissioning project to make my instrumentation decisions inspectable. All displayed gas data are synthetic.

1. **0:00–1:00 — Purpose.** Open the README and explain the three separate layers: embedded acquisition demonstration, live Python NH3 twin, and the new industrial protocol/persistence bench. Point to the [requirements matrix](marvela_alignment.md). No specific component brand is required by the public advertisement.
2. **1:00–2:00 — Hardware.** Open Virtual Hardware. Distinguish the real component photos from the virtual wiring diagram. Explain DHT GPIO4, ADC1 GPIO34 and SD SPI18/19/23/5. MQ-2 is not a selective NH3 instrument. Describe why RS-485 needs a transceiver and why 3.3 V levels matter.
3. **2:00–3:00 — Troubleshooting.** On Fault Injection, disconnect network, then fail storage. Observe independent queues/status, restore only network, then restore storage. Explain the original queues' volatile lifetime.
4. **3:00–4:30 — Industrial interface.** Open Commissioning Bench. Show unit/function/registers and CRC, switch from OK to BAD_CRC then TIMEOUT. Raw gas values remain while references become missing. Explain: I implemented and host-tested the Modbus RTU protocol logic in the ESP32 firmware; the optional UART2 adapter is compiled, while the physical RS-485 electrical layer remains a proposed bench test.
5. **4:30–5:30 — Recovery.** Run the commissioning campaign: 120 stored records, 110 valid references, 10 reference faults, zero pending after recovery. Run again to show stable identities. Explain the automated reopen/lost-ack tests, and that desktop SQLite is not proven embedded flash durability.
6. **5:30–7:00 — Science.** Open Calibration & Validation. Explain earlier training/later holdout, reference uncertainty, residuals and descriptive Bland–Altman limits. Open the ready-made `docs/validation_example/` report and coefficient artifact with units, training dates and source hash; no terminal command is needed. Avoid interpreting synthetic error as physical accuracy.
7. **7:00–8:00 — Next experiment.** Use the laboratory-to-farm gates in the alignment document: actual instrument selection, power/wiring checks, traceable calibration, independent validation, reliability trials and a co-located farm pilot. Discuss agreed acceptance criteria and uncertainty rather than claiming deployment readiness.

If asked whether this matches every qualification: it demonstrates design, programming and analysis decisions. It cannot establish a doctorate, scientific project-management experience or completed laboratory campaigns.
