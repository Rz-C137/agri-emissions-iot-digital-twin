# Limitations

- All Python gas and environmental records are synthetic.
- Wokwi is an embedded integration layer, not a digital twin of a farm.
- Wokwi runtime and serial output are not claimed unless separately observed and recorded.
- MQ-2 is an analog acquisition surrogate, not a selective NH3 instrument.
- NH3-B1 integration and its analogue front-end are design-stage.
- SCD41 firmware/build support does not constitute physical bench validation.
- RS-485/Modbus protocol software is tested; physical transceiver, cable, termination and reference-instrument operation are pending.
- No physical wiring, soldering, voltage measurement, calibration gas, reference traceability, farm campaign, PCB fabrication, EMC, ATEX or field qualification is claimed.
- Synthetic validation demonstrates analysis workflow only and does not establish sensor accuracy or field validity.
- The Streamlit dashboard does not ingest live ESP32 telemetry.
